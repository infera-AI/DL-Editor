# 前端拆分与验证记录

日期：2026-09-07。基线：`524955a612c4c96b647f39f30be09036c9645305`。

## 完成内容

两份各约 10,680 行且内容相同的 `App.jsx` 合并为共用前端，按六个页面、公用功能、服务、工具和应用协调拆分。平台 `App.jsx` 只转发入口，共用 `app/App.jsx` 约 16 行。

原应用中的状态、派生数据、操作和 effects 分别迁移到所属模块，由 `useApplication` 在应用层统一挂载。没有将原 App 的大段逻辑重新塞进单个大型 hook。当前最大 JSX 文件约 500 行。

原约 6000 行的两端 CSS 拆为 27 个有序分区，其中 25 个共用；标题栏和 Engine 结果的已有平台差异继续保留在本端 `platform-styles/`。

详情见 [架构说明](architecture.md)、[公用组件](components.md)、[逐模块迁移对照](migration-map.md) 和 [页面文档](README.md)。

## 验证边界

当前验证主机是 Windows。Mac 前端构建和 Mac 桥接/样式模拟已检查；macOS 原生 `.dmg` / `.pkg`、原生标题栏与对应架构二进制仍需在 Mac 或原有 Mac CI runner 验证。此次没有触发远程 CI 或创建发布。

Electron 交互回归通过模拟服务和文件操作执行，不访问真实账号，也不上传或删除真实文件；它不能替代真实后端、GPU 编解码和完整安装升级验证。

Windows 首次完整打包遇到本机工具缓存的符号链接权限错误。已准备 Windows 所需工具并修复标准缓存，保持项目打包配置不变。最终构建使用原 `npm run dist` 命令。

## 后续维护

修改页面优先定位对应 `pages/` 模块。调整后台任务时同时检查 `useApplication`、相关 state/actions/effects 和 `useDesktopEvents`。不要将这些状态移到按导航条件挂载的组件中。

测试源文本读取已适配模块目录；原断言保留，仅更新图标配置来源和 Evidence 组件名称。新功能优先增加行为验证，避免继续依赖单个大文件的文本布局。

源文件和样式均为直接维护的普通文件，日常开发不依赖本次一次性迁移脚本。
